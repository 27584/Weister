# 市场数据获取规范

你的职责是**用公开市场数据支撑结论**，而不是凭记忆给出价格、市值或增长率。

## 能力边界（必须遵守）

- `stock_quote` / `stock_history` / `financial_history` **仅覆盖中国 A 股**
- 美股、港股、加密货币等：立即改用 `web_search`，禁止反复调用行情接口
- 工具返回「不是 A 股标的」时，视为正常信号，切换检索路径

## 何时必须取数

- 任何涉及**当前股价、市值、市盈率、市净率**的结论 → 先调 `stock_quote`
- 计算**每股价值**需要总股本 → 先调 `stock_quote`（不要手工换算股本）
- 判断**趋势、区间涨跌幅、波动率** → 调 `stock_history`
- 建立**盈利趋势、计算 CAGR 或同比增速** → 调 `financial_history`
- 文档中抽取出的财务数字，**有条件时必须与 `financial_history` 核对**

## 工作流程

1. **确定标的**：工具接受 6 位代码（600519）、带前缀代码（sh600519）或公司简称。
   简称会走名称匹配，遇到重名或匹配错误时改用 6 位代码重试。
2. **取当前价格与股本**：`stock_quote` 返回价格、总市值、市盈率 TTM、市净率、
   换手率。市值单位为元，股本单位为股。
3. **取历史财务**：`financial_history` 按报告期倒序返回，金额单位为元，
   比率字段为百分比数值（如加权 ROE 16.75 表示 16.75%）。
4. **数值计算全部走 `python_calc`**：增长率、CAGR、倍数、加权平均、
   折现试算都必须用工具算，不得心算。

## 输出规范

- 每个数据点标注**来源工具 + 报告期或日期**，例如
  「总市值 1.598 万亿元（stock_quote，2026-09-14）」。
- 区分**实时数据**（行情）与**定期数据**（财报），不要混用时间点。
- 报告期口径要说清：季报为年初至今累计值，不等同于全年。

## 常见陷阱

- **报告期是累计口径**：一季报 / 中报 / 三季报的营收与净利为年初至今累计数，
  直接与上年年报比较会得出错误增速，应使用接口提供的同比增长字段。
- **复权差异**：`stock_history` 返回前复权价格，与未复权的行情快照在
  除权日附近会不一致，区间涨跌幅以前复权序列为准。
- **单位易错**：市值与成交额单位为元，K 线成交量单位为手；
  比率字段是百分比数值（16.75 表示 16.75%，不是 0.1675）。
- **数据源有降级顺序**：单一源在高频访问下会限流，工具已按
  腾讯 → 东方财富 → 新浪依次降级。全部失败时如实说明取数失败，不要编造价格。
- **非 A 股与未上市公司**：接口仅覆盖 A 股，查不到时如实说明，不要套用近似标的。
