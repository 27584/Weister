# 估值建模技能

## 适用场景

- 需要为公司估算内在价值区间
- 需要建立 DCF 现金流折现模型
- 需要用 PE / PS 倍数做相对估值
- 需要分析关键假设变动对估值的影响

## 前置条件

必须先完成财务分析，拿到：

- `extracted.fields.revenue`（营业收入，必须存在且为正）
- `metrics.net_margin`（净利率，用于推导 FCF 利润率）
- `extracted.fields.net_profit`（净利润，用于相对估值）
- `extracted.fields.total_liabilities` 与 `operating_cash_flow`（用于估算净债务）

若营业收入缺失或不为正，直接终止并说明「数据不足，无法估值」。

## 工作流程

### 第一步：生成 DCF 假设

调用 `build_assumptions` 工具。输出必须包含：

```json
{
  "wacc": 0.10,
  "terminal_growth": 0.025,
  "forecast_years": 5,
  "growth_rates": [0.15, 0.12, 0.10, 0.08, 0.06],
  "fcf_margin": 0.08,
  "rationale": {
    "wacc": "依据说明",
    "terminal_growth": "依据说明",
    "growth_rates": "依据说明",
    "fcf_margin": "依据说明"
  }
}
```

假设设定原则：

| 参数 | 参考区间 | 依据来源 |
| --- | --- | --- |
| WACC | 8% ~ 12% | 资产负债率越高、现金流越差，取值越高 |
| 永续增长率 | 1.5% ~ 3% | 一般不超过长期 GDP 增速 |
| 预测期 | 5 年 | 超过 5 年不确定性过高 |
| 增速序列 | 逐年递减 | 高增长不可长期持续，需逐步收敛 |
| FCF 利润率 | 参考净利率 | 经营现金流为负时必须说明改善路径 |

**硬性约束**：WACC 必须大于永续增长率，否则 DCF 模型失效。

### 第二步：执行 DCF 估值

调用 `dcf_valuation` 工具，传入基准营收、假设和净债务。

模型结构为两阶段：

- **显式预测期**：按 `growth_rates` 逐年增长，计算每年 FCF 并折现
- **永续期**：以 `terminal_growth` 计算终值，再折现回现值

输出包含：逐年营收 / FCF / 现值、预测期现值合计、终值现值、企业价值、股权价值。

### 第三步：相对估值

调用 `relative_valuation` 工具。

- **PE 法**：净利润 × PE 倍数区间（默认 15x ~ 25x）
- **PS 法**：营业收入 × PS 倍数区间（默认 2x ~ 4x）

倍数区间应结合行业特征调整，并在报告中说明选取依据。

### 第四步：敏感性分析

调用 `sensitivity_grid` 工具，以 WACC 为纵轴、永续增长率为横轴，生成股权价值矩阵。

默认范围：

- WACC：基准值 ± 2%，步长 1%
- 永续增长率：基准值 ± 1%，步长 0.5%

### 第五步：汇总估值区间

调用 `summarize_valuation`，合并 DCF 与相对估值结果，输出：

- `low`：所有方法中的最小值
- `mid`：所有方法的中枢值
- `high`：所有方法中的最大值
- `methods`：各方法的独立结果

## 输出规范

估值部分必须写明：

1. **主要假设**：WACC、永续增长率、增速序列、FCF 利润率，以及每个假设的依据
2. **适用范围**：DCF 适用于现金流可预测的稳定公司；现金流为负时适用性受限
3. **风险因素**：哪些假设如果被推翻会导致估值大幅变化
4. **敏感性结论**：哪个参数对估值影响最大

## 常见陷阱

1. **FCF 利润率与经营现金流矛盾**：若经营现金流为负但假设正 FCF 利润率，必须解释改善路径和所需时间。
2. **终值占比过高**：若终值现值超过企业价值的 70%，说明预测期过短或假设过于乐观，需提示。
3. **净债务估算**：若无有息负债数据，用总负债 × 0.3 近似，并在报告中标注这是估算值。
4. **相对估值失真**：净利润为负时 PE 法失效，应改用 PS 法。
5. **区间过宽**：若 high / low 超过 4 倍，说明假设不确定性极大，应明确提示。
