# 投资简报撰写技能

## 适用场景

- 综合多位专家的分析意见，形成统一结论
- 撰写面向投资决策的研究报告
- 需要明确区分事实、推论与观点

## 报告结构

严格按以下顺序组织：

### 一、摘要与核心结论

用 3 ~ 5 句话概括最重要的发现。必须包含：

- 公司当期营收与利润规模
- 盈利质量判断（一句话）
- 估值区间
- 最终建议方向

### 二、盈利质量分析

- 营收与利润规模、增速
- 净利率水平
- **利润与现金流匹配度**（若背离，放在首位）
- 数据缺失项

### 三、现金流风险分析

- 经营现金流金额与趋势
- 现金收入比
- 资产负债结构
- 风险传导路径

### 四、估值分析

分三部分：

1. **DCF 估值**：假设、适用范围、风险因素、结果
2. **相对估值**：PE / PS 区间与隐含市值
3. **综合区间**：下限、中枢、上限，以及各方法的权重说明

### 五、风险与反向验证条件

用表格呈现，每行包含：

| 风险点 | 描述 | 反向验证条件 |
| --- | --- | --- |
| 现金流风险 | 经营现金流持续为负 | 连续两期经营现金流转正 |
| 假设风险 | FCF 利润率假设偏乐观 | 实际 FCF 利润率达到假设值 |

**反向验证条件必须可执行**：写清楚「什么数据出现就说明风险解除」，不要写「需持续关注」这类空话。

### 六、数据不足说明

逐条列出影响分析完整性的缺失数据，以及缺失导致的分析局限。

### 七、结论与建议

- 明确给出方向性判断
- 列出后续需要跟踪的关键指标
- 附参考来源

## 写作规范

### 标注体系

- 【事实】：直接来自原始数据或原文
- 【推论】：基于数据的逻辑推导
- 【观点】：主观判断，需说明依据

### 引用格式

关键结论后标注来源，格式为 `[p3]` 表示第 3 页。引用专家意见时标注专家名，如 `[风险审查员]`。

### 语言要求

- 不用「可能」「或许」这类模糊词，改为明确的条件句：「若 X 则 Y」
- 不写「综上所述」这类套话
- 数字保留合理精度，金额统一为亿元并保留两位小数

## 常见陷阱

1. **堆砌专家意见**：不是把四位专家的原文拼在一起，而是提炼共识、标注分歧。
2. **回避负面结论**：若数据确实显示风险，必须明确写出，不要用「有待观察」模糊处理。
3. **估值区间过宽时不做说明**：区间跨度超过 3 倍时，必须解释原因。
4. **遗漏数据缺失说明**：任何影响结论的数据缺失都必须在第六部分列出。
