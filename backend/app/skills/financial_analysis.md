# 财务分析技能

## 适用场景

当你需要完成以下任务时，加载本技能：

- 从年报、半年报、季报或公告中提取标准化财务字段
- 评估公司盈利质量（净利率、利润与现金流匹配度）
- 判断现金流健康度（经营现金流、现金收入比）
- 分析资产负债结构（负债率、偿债压力）

## 工作流程

### 第一步：结构化抽取

调用 `extract_fields` 工具，传入财报全文。

必须遵循的原则：

1. **不做推测**：文本中没有的字段一律填 `null`，绝不根据行业常识或历史数据补全。
2. **保留原文证据**：每个提取到的字段都要在 `evidence` 中给出原文片段和页码。
3. **单位归一**：识别文本中的单位（元 / 万元 / 百万元），在 `unit` 字段中标注，数值保持原样不做换算。
4. **区分合并口径**：优先提取「归属于上市公司股东的净利润」，而非「净利润」总额，并在 `period` 中标注报告期。

输出结构：

```json
{
  "company": "公司名称或 null",
  "period": "2024年报",
  "currency": "CNY",
  "unit": "元",
  "fields": {
    "revenue": 数值或 null,
    "net_profit": 数值或 null,
    "gross_margin": 数值或 null,
    "operating_cash_flow": 数值或 null,
    "total_assets": 数值或 null,
    "total_liabilities": 数值或 null,
    "eps": 数值或 null,
    "shares_outstanding": 数值或 null
  },
  "evidence": [
    {"field": "revenue", "quote": "原文片段", "page": 1}
  ]
}
```

### 第二步：派生指标计算

调用 `compute_metrics` 工具，传入上一步的抽取结果。

该工具为确定性计算，不涉及模型判断。输出的指标包括：

| 指标 | 含义 | 判读要点 |
| --- | --- | --- |
| `net_margin` | 净利率 | 低于 5% 说明盈利能力弱 |
| `ocf_to_revenue` | 经营现金流 / 营收 | 持续为负说明盈利未转化为现金 |
| `debt_ratio` | 资产负债率 | 高于 70% 需警惕偿债压力 |
| `profit_cash_gap` | 经营现金流 - 净利润 | 为负且绝对值大说明利润含金量低 |
| `profit_cash_divergence` | 利润现金流背离标记 | 为 true 时必须重点说明 |

## 输出规范

撰写分析结论时：

- **区分事实与推论**：直接来自数据的陈述标【事实】，基于数据推导的标【推论】。
- **标注数据来源**：关键结论后附页码，如 `[p3]`。
- **明确数据缺失**：无法计算的指标写「数据不足」，不要用行业均值替代。
- **现金流优先**：若 `profit_cash_divergence` 为 true，必须放在分析首位。

## 常见陷阱

1. **净利润为负时的比率失真**：净利率、利润现金缺口在净利润为负时方向会反转，需单独说明。
2. **非经常性损益**：若文本提及政府补助、资产处置收益，应提示其对利润的影响。
3. **会计口径变化**：若报告期调整了会计政策，需对比新旧口径。
4. **单期数据局限**：只有一期报告时无法判断趋势，必须明示这一局限。
